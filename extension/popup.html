Connect with your Dgmos access key; captured leads go straight to Dgmos CRM.

How to get your access key

  1. Open Dgmos → Services → API Keys and click Create new API key.
  2. Key type: choose Public key.
  3. Module route permissions: tick Lead Management, then click Next.
  4. Allowed IP addresses: enter chrome-extension://bdocdakjpdgbdbajcifckjjcclgonegc
  5. Click Create new API key, copy the Access key it shows and paste it above.
